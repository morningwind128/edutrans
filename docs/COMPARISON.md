# EduTrans 与沉浸式翻译 功能逐项对比

| 功能 | 沉浸式翻译 | EduTrans | 说明 |
|---|---|---|---|
| 网页双语对照 | ✅ | ✅ | 双语/仅译文;视口渐进翻译;Alt+A |
| 翻译引擎 | 谷歌/微软/DeepL/AI(Pro 会员模型) | **设备端离线(内置)**、Google/微软(内置)、自定义 OpenAI 兼容 | 设备端翻译用 Chrome 自带本地模型,不依赖外部服务 |
| 上下文感知翻译 | 部分(仅 AI 引擎) | ✅ | 页面标题+整批段落+术语表一起参与,整页译名一致 |
| AI 专家/自定义提示词 | ✅ Pro | ✅ | 每个自定义服务可填补充系统提示词 |
| 术语库 | ✅ Pro | ✅ 免费 | AI 严格遵循;免费引擎整词替换 |
| **AI 页面摘要** | ❌ | ✅ Alt+S 随时唤起 | 悬浮面板,内容只发给你自己配置的接口 |

| 划词翻译 | ✅ | ✅ | 气泡翻译+收藏 |

## 已知差异(诚实声明)

- 免费引擎(Google/微软)为逐句直翻,无整页一致性;设备端引擎质量取决于
  Chrome 本地模型;追求最佳质量请配置 AI 服务(如 GLM 免费模型)。
- 悬浮球未做,以工具栏弹窗 + 快捷键替代。
- PDF/EPUB/漫画翻译未实现,见 Roadmap。
